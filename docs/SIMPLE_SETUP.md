# Simple Setup

Normal users should not need CLI flags.

Install AI Usage Window Scheduler, enter one daily wake time in the native macOS dialog, and finish. The schedule applies every day, including weekends. The menu-bar widget starts automatically and shows usage/reset information for supported AI providers.

The generated app is installed at:

`~/Applications/AI Usage Window Scheduler.app`

Open it any time to change the daily Claude wake time. The menu-bar widget also includes **Change wake time…**.

Advanced CLI commands remain available for developers and custom provider integrations.
